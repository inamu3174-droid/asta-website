# ASTA

**From Kashmir, Closer to You.**

Premium editorial website for ASTA — authentic Kashmiri honey, Mongra saffron, Kahwa and dry fruits.

## Live

Connect this repository to Vercel for automatic deployment:

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import the repository `inamu3174-droid/asta-website`
3. Deploy (static HTML, no build step required)
4. In Project Settings → Deployment Protection → disable Vercel Authentication so the site is public
