**From Kashmir, Closer to You.**

Ultra-premium editorial website for ASTA — authentic Kashmiri saffron, white honey, Kahwa and dry fruits.

## Live

1. Connect this repo to [Vercel](https://vercel.com/new)
2. Framework: **Other** (static HTML)
3. Deploy
4. Disable **Deployment Protection** so the site is public

- Cinematic loading screen
- Immersive product experiences (Dry Fruits, Kahwa, Raw Mongra Saffron, White Honey)
